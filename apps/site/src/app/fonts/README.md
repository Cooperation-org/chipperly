# Fonts

Alegreya and Alegreya Sans (SIL OFL), Latin subsets, the same files as `apps/web/app/fonts/`. Self-hosted so a build never depends on reaching Google Fonts.

`twemoji-chipperly.woff2` is the app's Twemoji subset (Twemoji Mozilla 0.7.0, CC-BY 4.0, graphics by Twitter), copied from `apps/web/app/fonts/`. Used only by the hero demo (`components/HeroDemo.tsx`).
